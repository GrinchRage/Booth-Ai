Selfie realistici da una foto

Carica una o più persone e genera 4 selfie realistici. I dettagli distintivi (tatuaggi, piercing, nei, segni particolari) restano fedeli alla foto originale salvo richiesta esplicita nel prompt libero.

API gratuita

Come funziona

  1. Carica una foto con una o più persone.
  2. Seleziona una categoria preset e aggiungi un prompt libero.
  3. Il prompt include sempre l’istruzione di mantenere tatuaggi, segni particolari, piercing, nei e difetti.
  4. Generiamo 4 immagini una dopo l’altra, ognuna con download.
